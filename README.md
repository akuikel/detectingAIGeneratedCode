# Detecting AI-Generated Source Code — Extended Study

> An extension of the ICSE 2025 paper **"An Empirical Study on Automatically Detecting AI-Generated Source Code: How Far Are We?"**  
> [arXiv:2411.04299](https://arxiv.org/abs/2411.04299) · Original repo: [JaeWorld/ICSE2025-AI-Detector](https://github.com/JaeWorld/ICSE2025-AI-Detector)

**Author:** Aavash Kuikel — Fisk University, Computer Science

**Live demo:** [akuikel-codedetector.hf.space](https://akuikel-codedetector.hf.space)

---

## Overview

This project extends the original ICSE 2025 study by evaluating **three new state-of-the-art LLMs** that were not tested in the original paper, using the same HumanEval-X benchmark and a CodeBERT + Logistic Regression classification pipeline.

| Model | Role |
|---|---|
| **Claude Haiku** (Anthropic) | First Claude model evaluated for AI code detection |
| **GPT-4o** (OpenAI) | Successor to GPT-4 from the original paper |
| **Gemini 2.5 Flash** (Google) | Successor to Gemini Pro from the original paper |

---

## Key Finding

**Newer LLMs are easier to detect, not harder.**

Our classifier achieves F1 scores of **0.97–0.99** on the new models — significantly higher than the original paper's best of 0.8255 on ChatGPT. This suggests newer LLMs produce more structurally consistent code with recognizable patterns, making them more distinguishable from human-written code.

| Model | Embedding | F1 | Human F1 | AI F1 |
|---|---|---|---|---|
| ChatGPT *(original paper)* | Combined | 0.8255 | 0.8369 | 0.8141 |
| **Claude Haiku** *(ours)* | Code | 0.9695 | 0.9681 | 0.9710 |
| **Claude Haiku** *(ours)* | AST | 0.9817 | 0.9818 | 0.9816 |
| **Claude Haiku** *(ours)* | Combined | 0.9756 | 0.9745 | 0.9768 |
| **GPT-4o** *(ours)* | Code | 0.9787 | 0.9781 | 0.9793 |
| **GPT-4o** *(ours)* | AST | 0.9635 | 0.9629 | 0.9641 |
| **GPT-4o** *(ours)* | Combined | 0.9879 | 0.9874 | 0.9883 |
| **Gemini 2.5** *(ours)* | Code | 0.9847 | 0.9848 | 0.9847 |
| **Gemini 2.5** *(ours)* | AST | 0.9818 | 0.9820 | 0.9815 |
| **Gemini 2.5** *(ours)* | **Combined** | **0.9939** | **0.9939** | **0.9939** |

## Web App

This project includes **CodeSense** — a web interface where anyone can paste Python code and instantly see whether it was written by a human or generated by AI, along with a confidence percentage.

**Try it live:** [akuikel-codedetector.hf.space](https://akuikel-codedetector.hf.space)

### How it works

```
User pastes code
       ↓
Variable names normalised (tree-sitter)
       ↓
AST sequence extracted
       ↓
Code + AST embedded with CodeBERT (768-dim each → 1536-dim combined)
       ↓
Logistic Regression classifier
       ↓
Verdict + % confidence returned
```

### Run locally

```bash
# From the repo root — train and save the model (one-time)
python webapp/train_model.py

# Start the server
python webapp/app.py
# → http://localhost:8000
```

## Research Pipeline

The full 5-step pipeline used to produce the results:

```
generateCode.py          →  Query LLMs for solutions to 164 HumanEval-X problems
prepareDataset.py        →  Merge AI code + human code, add labels (0=AI, 1=Human)
generateAST.py           →  Parse code into AST token sequences via tree-sitter
generateEmbeddings.py    →  Embed code + AST with CodeBERT, create K-fold splits
runClassifier.py         →  Train Logistic Regression, report F1 / accuracy / precision
```

## Running the Research Pipeline

### Prerequisites

- Python 3.11 or 3.12
- ~3 GB disk space
- API keys for Anthropic, OpenAI, and Google

### Setup

```bash
git clone https://github.com/akuikel/detectingAIGeneratedCode.git
cd detectingAIGeneratedCode

pip install -r requirements.txt

# Clone tree-sitter grammars (specific versions required)
git clone --depth 1 --branch v0.20.4 https://github.com/tree-sitter/tree-sitter-python
git clone --depth 1 --branch v0.20.1 https://github.com/tree-sitter/tree-sitter-java
git clone --depth 1 --branch v0.20.3 https://github.com/tree-sitter/tree-sitter-cpp

# Compile grammars (one-time)
python buildGrammar.py
```

### API Keys

Add your keys to `generateCode.py`:

```python
ANTHROPIC_API_KEY = "sk-ant-..."
OPENAI_API_KEY    = "sk-proj-..."
GOOGLE_API_KEY    = "AIza..."
```

| Provider | Where to get it | Approx. cost |
|---|---|---|
| Anthropic | console.anthropic.com | ~$0.50 |
| OpenAI | platform.openai.com/api-keys | ~$1.00 |
| Google | aistudio.google.com/app/apikey | Free tier available |

### Run

```bash

python prepareDataset.py
python generateAST.py

python runClassifier.py       # Prints results table
```

If embeddings already exist, jump straight to:
```bash
python runClassifier.py
```

## Methodology

1. **Dataset:** 164 Python problems from the [HumanEval-X](https://github.com/THUDM/CodeGeeX) benchmark
2. **Code generation:** Each LLM was prompted with a function signature and docstring and asked to return only the function body
3. **Preprocessing:** Variable names normalised, comments stripped via tree-sitter
4. **Feature extraction:** Code and AST sequences embedded with [microsoft/codebert-base](https://huggingface.co/microsoft/codebert-base) (768-dim CLS token). Three variants tested: code-only, AST-only, combined (1536-dim)
5. **Classification:** Logistic Regression with 5-fold stratified cross-validation, `random_state=42`
6. **Evaluation:** Macro-average F1 (average of Human F1 and AI F1)

> The original paper used CodeT5+ 110M for embeddings. This extension uses CodeBERT — the same model used in GPTSniffer, the paper's state-of-the-art baseline — making results directly comparable.
